# Roadmap

## Milestone 1: Public scaffold

- Public repository, license, README, and contribution-ready structure.
- Minimal examples that do not reveal manuscript-specific result tables.

## Milestone 2: Core audit utilities

- Fourier surrogate fitting utilities.
- Finite-sample audit certificate utilities.
- Clear interpretation guardrails.

## Milestone 3: Reproducible examples

- Synthetic examples.
- Toy QNN-style frozen model examples.
- Public benchmark ledgers not tied to blind-review-sensitive manuscript artifacts.

## Milestone 4: Paper artifact release

- Full reproduction package after journal-submission/review constraints are resolved.
