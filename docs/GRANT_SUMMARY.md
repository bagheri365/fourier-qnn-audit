# Grant Summary

## Project

Fourier QNN Audit Toolkit: open-source infrastructure for auditing trained quantum neural networks with compact Fourier surrogate models and finite-sample validation protocols.

## Problem

Quantum neural networks are often evaluated by task accuracy, but researchers also need tools to inspect the learned input-output behavior of a frozen trained model.

## Deliverables

- Python package for Fourier surrogate audits.
- Documentation and interpretation guardrails.
- Tutorial notebooks or examples.
- Reproducible public benchmark ledgers.

## Why this matters

The project contributes transparent, reproducible infrastructure for quantum machine learning evaluation and helps distinguish model behavior from label-trained classical baseline performance.
